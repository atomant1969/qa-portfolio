# TypeScript QA Portfolio

This directory mirrors the full QA portfolio map using Playwright TypeScript examples.

```text
typescript/
|-- 01-api-tests/
|-- 02-ui-tests/
|-- 03-e2e-tests/
|-- 04-load-tests/
|-- 05-integration-tests/
|-- 06-database-tests/
|-- 07-security-tests/
|-- 08-mobile-tests/
|-- 09-performance-tests/
|-- 10-test-utilities/
|-- 11-ci-cd/
|-- 12-ai-assisted-testing/
`-- 13-documentation/
```

Each numbered directory is treated as a standalone mini-project with its own `package.json`, Playwright config, tests, fixtures, and README or documentation files.
