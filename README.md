# QA Automation Portfolio

This repository is organized by automation language. Each language contains the same numbered QA capability map so recruiters can quickly scan API, UI, E2E, load, database, security, mobile, performance, utility, CI/CD, AI, and documentation examples.

| Directory | Purpose |
| --- | --- |
| `python/` | Python QA portfolio: API tests, UI test scaffold, utilities, JMeter examples, data analysis, and AI-assisted workflows. |
| `typescript/` | TypeScript QA portfolio area for Playwright and related automation examples. |

Start with:

- `python/README.md` for Python examples.
- `typescript/README.md` for Playwright TypeScript examples.
